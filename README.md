# Project Omen

A desktop application for editing and managing RPG game data files.

## Download

**[Download Latest Release (v0.0.1)](https://github.com/michaelaaron81/ProjectOmen/releases/latest)**

### Installation Note
Windows may show a security warning because this is unsigned software. This is normal for free software:
1. Click "More info" when the warning appears
2. Click "Run anyway" to proceed with installation
3. Follow the setup prompts

## Features

- **Visual Editor**: Edit game data with structured forms and validation
- **Collapsible Sections**: Organize complex data with collapsible UI elements
- **Drag & Drop Reordering**: Rearrange records with drag & drop or keyboard shortcuts
- **Raw Text Editor**: Direct access to pipe-delimited data with find/replace
- **Arrow Key Navigation**: Navigate records with keyboard for efficient editing
- **Auto-save**: Work is automatically saved locally to prevent data loss
- **Offline First**: All data stays on your device, no internet required
