=== D&D 5e-Style RPR System Example ===

Source: Alymer (Epsindi)
Purpose: Demonstrates that complex D&D 5e mechanics ARE implementable in RPR
Key Features:
- Attack Bonus, Damage Bonus, Armor Class, Spell Save DC
- 6 Core Attributes (STR, DEX, CON, INT, WIS, CHA)
- Organized skill hierarchy using hidden attributes
- 69 Mutators for attribute-based calculations
- Armor weight classes with DEX modifiers
- Weapon properties (Finesse, Ranged)
- Proficiency bonus system

=== DESIGN PATTERNS EXPLAINED ===

Pattern for Adding Attribute-Based Bonuses to Stats:
1. Create an item that's a rune (Optional, can be done with just perks)
2. Create a prerequisite perk
3. Apply this perk to the rune OR nest it in a grander perk
4. Perk follows the pattern to add to stats based on attribute points
5. Modify other mutators to exclude their modifications when another perk is active

Mutator Organization Pattern (6 mutators per stat):
- 2 Points: +1 bonus
- 4 Points: +2 bonus (exclude if 6/8 point perk active)
- 6 Points: +3 bonus (exclude if 8 point perk active)
- 8 Points: +4 bonus
- Skill Perk: +2 bonus (for skill proficiency)
- Expertise Perk: +4 bonus (double proficiency)

Example: Attack Bonus gets 6 mutators from each attribute
- "Attack Bonus - Strength 2": +1 if STR >= 2
- "Attack Bonus - Strength 4": +1 if STR >= 4 (exclude if 6/8 perk)
- "Attack Bonus - Strength 6": +1 if STR >= 6 (exclude if 8 perk)
- "Attack Bonus - Strength 8": +1 if STR >= 8
- "Attack Bonus - Str Profi": +2 if has STR proficiency perk
- "Attack Bonus - Str Expert": +2 if has STR expertise perk (total +4)

Armor Class Pattern:
- Base AC = 10
- Light Armor: +Armor bonus +DEX modifier
- Medium Armor: +Armor bonus +DEX modifier (max +2)
- Heavy Armor: +Armor bonus only (no DEX)

Weapon Properties:
- Finesse: Can use DEX OR STR for attack/damage
- Ranged: Uses DEX for attack/damage typically

=== IMPLEMENTATION NOTES ===

Armor Examples:
- 833101 = Studded Leather (+3 AC, Light Armor, full DEX bonus)
- 833126 = Half Plate (+5 AC, Medium Armor, DEX bonus capped at +2)
- 833151 = Full Plate (+8 AC, Heavy Armor, no DEX bonus)

The mutator exclusion system ensures correct behavior:
- Light armor: Mutators 60-65 apply (all DEX bonuses)
- Medium armor: Mutator 69 excludes 62-65, allowing only +2 DEX
- Heavy armor: Mutator 71 excludes all DEX bonuses (60-65)

Proficiency vs Expertise:
- Proficiency: +2 bonus to stat
- Expertise: Additional +2 bonus (total +4)
- Expertise perks should require proficiency perks as prerequisites

Attribute Point Allocation Strategy:
- Even numbers (2,4,6,8) give +1 per 2 points
- Odd numbers waste points (5 gets same bonus as 4)
- This matches D&D 5e's modifier progression
