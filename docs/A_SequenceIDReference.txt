# RPR SEQUENCE ID REFERENCE
# This document defines which columns contain Node IDs and what table they reference.
# Used by handleSequence to correctly remap IDs after sequencing.

================================================================================
                         NODE ID COLUMN MAPPINGS
================================================================================

## PARENT TABLES (Get sequenced, create ID mappings)

| Table      | ID Column | ID Column Index | Notes                          |
|------------|-----------|-----------------|--------------------------------|
| SkillDef   | Node ID   | 2               | Unique - only table with ID in col 2 |
| PerkDef    | ID        | 1               |                                |
| Stat       | ID        | 1               |                                |
| Rune       | Node ID   | 1               | Parent of RuneAction           |
| RuneDef    | Node ID   | 1               | Parent of RuneCondition, RuneEffect |
| SpellDef   | ID        | 1               |                                |
| StatusDef  | ID        | 1               |                                |
| MutatorDef | ID        | 1               |                                |


================================================================================
                         CHILD TABLE → PARENT MAPPINGS
================================================================================

| Child Table     | Parent Table | Parent ID Column |
|-----------------|--------------|------------------|
| PerkAction      | PerkDef      | 1                |
| RuneAction      | Rune         | 1                | ← NOT RuneDef! |
| RuneCondition   | RuneDef      | 1                |
| RuneEffect      | RuneDef      | 1                |
| SpellEffect     | SpellDef     | 1                |
| SpellReqDef     | SpellDef     | 1                |
| SpellTargetCond | SpellDef     | 1                |
| StatusAction    | StatusDef    | 1                |
| MutatorAction   | MutatorDef   | 1                |
| MutatorCondition| MutatorDef   | 1                |


================================================================================
                         FORMULA FIELDS (Reference SkillDef IDs)
================================================================================

Format: "NodeID*Multiplier;NodeID*Multiplier" (e.g., "2*1.0;1*0.5")

| Table    | Column | Column Index | Description      |
|----------|--------|--------------|------------------|
| SkillDef | Bonus Source | 7      | References SkillDef Node IDs |
| Stat     | Formula      | 4      | References SkillDef Node IDs |

                  Col 1   Col 2    Col 3     Col 4

|----------|------------------|---------------------|
| 0        | Allow Skill      | SkillDef            |

| 3        | Deny Perk        | PerkDef             |
| 4        | Dice Modifier    | SkillDef            |
| 5        | Give Feat        | (external)          |
| 6        | Grant Stat       | Stat                |
| 7        | Stat Modifier    | Stat                |
| 8        | Grant Ability    | SpellDef            |
| 9        | Grant Status     | StatusDef           |
| 10       | Unlock Status    | StatusDef           |
| 11       | Grant Perk       | PerkDef             |
| 12       | Grant Sudo Role  | (external)          |
| 13       | Allow Perk Cat   | (uses Modifier col) |
| 14       | Deny Perk Cat    | (uses Modifier col) |
| 15       | Teach Language   | (external)          |
| 16       | Give CharTag     | (external)          |
| 17       | Set Float CharVar| (external)          |
| 18       | Set String CharVar| (external)         |

================================================================================
                         SKIP TABLES (Don't sequence)
================================================================================

These tables should NOT have their IDs changed:
- DiceConfig
- DiceRules  
- Gear
- LookupClimate
- LookupShelter
- LookupTimeOfDay
- LookupMainHand
- LookupOffHand
- LookupArmorClass
- LookupBool
- LookupGender


================================================================================
                         EXTERNAL REFERENCES (Don't remap)
================================================================================

These values reference external game systems, not RPR Node IDs:
- SpellEffect col 5 when Effect=2 or 3 (Game Item IDs like 15002, 2491200)
- SpellReqDef col 4 when Function=6 (Conan Item ID)
- Rune col 2 (Game Item ID)
- PerkAction col 4 when Function=5,12,15,16,17,18 (external systems)
